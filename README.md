# dontforget
Repository for personal project of tracking subscriptions through Google Spreadsheets, Python script, and Cron

## Modules
### common_utility.py
- Common functions used in multiple scripts and modules

### gspread_utility.py
- Client and functions for Google Spreadsheets API

### pandas_utility.py
- Functions for cleaning dataframes using Pandas

### sql_utility.py
- Module for running SQL scripts and querying data from `dontforget` db

### summary_stats.py
